Ця інструкція описує, як масово додавати або оновлювати параметри у файлі CountryData.json за допомогою Node.js скрипта.

### Структура файлів

Скрипт та файл даних мають знаходитися в одній директорії:
CountryData.json — основна база даних.
update_json.js — скрипт автоматизації.

### Як додати нове поле або оновити наявні дані:

Відкрийте файл update_json.js у вашому редакторі коду (наприклад, VS Code).
Змініть назву поля у змінній FIELD_NAME на початку файлу (наприклад, const FIELD_NAME = "new_field_name";).
Оновіть об'єкт updatesData, додавши або змінивши пари slug: "значення" для потрібних країн.
Запустіть скрипт через термінал.

### Запуск скрипта

Відкрийте термінал (наприклад, Git Bash у корені вашого проєкту) та виконайте команду, вказавши шлях до вашого скрипта:

### Bash

node src/data/WorldMap/CountriesData/update_json.js
(Замініть шлях на актуальний для вашої структури папок).
Після успішного виконання в терміналі з'явиться повідомлення:
Успіх! Поле "fluent_speakers_percentage" успішно додано/оновлено для всіх об'єктів у CountryData.json.
Файл CountryData.json автоматично збережеться з відформатованим відступом у 2 пробіли.
